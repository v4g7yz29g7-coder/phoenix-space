# Phoenix — Дорожная карта: философские слои

## Горизонт 1: Стратегический

### PHIL-1: Философский манифест
- **Файл:** `docs/PHOENIX_PHILOSOPHY.md`
- **Статус:** ✅ готов (создан вручную)

### PUPPET-1: Кукловод (RL-оркестратор)
- **Файл:** `architect/puppeteer.js`
- **Задача:** RL-агент, управляющий пулом.
- **Наблюдения:** состояние пула, load, бюджет, история гонок.
- **Действия:** запуск гонок, приоритеты, смена стратегии.
- **Награда:** качество + бюджет + стабильность.

## Горизонт 2: Тактический

### CRITIC2-1: Детектор ошибок v2
- **Файл:** `boxes/agent_1/agent_critic.js`
- **Задача:** проверка решения против baseline топ-100 из `moat`.
- **API:** `checkAgainstBaseline(solution) → {ok, deviation, reason}`.

### RIGID-1: Жёсткие и гибкие звенья
- **Файл:** `boxes/agent_1/agent_loop_v3.js`
- **Задача:** два набора промптов — `HARD_SKILLS` и `SOFT_SKILLS`.
- **Критерий:** HARD содержит 5+ правил, SOFT — 5+ стратегий.

### SELFAWARE-1: Самовоспоминание
- **Файл:** `boxes/agent_1/_runner.js`
- **Задача:** периодический мета-промпт «что я делаю и почему».
- **Критерий:** вызов каждые N шагов, вывод в лог.

## Горизонт 3: Операционный

### POLY-1: Полифоническая гонка
- **Файл:** `race.js`
- **Задача:** каждому агенту — свой `RACE_TASK` (не общий).
- **API:** `RACE_TASKS_BY_BOX` как JSON.

### CHRONO-1: Карта хронотопов
- **Файл:** `architect_worker.js`
- **Задача:** у задачи есть `deadline` (время) и `scope` (пространство).
- **Критерий:** 10+ задач с новыми полями.

## Новые слои (нейронаука 2024–2025)

### INTERO-1: Интероцепция системы
- **Файл:** `sentinel.js` (расширить)
- **Задача:** метрики «дофамин» (успех/час) и «серотонин» (стабильность).
- **API:** `getMood() → {dopamine, serotonin}`.

### GNW-1: Глобальное рабочее пространство
- **Файл:** `memory/gnw.js`
- **Задача:** решения score > 8 → в общую базу.
- **API:** `ignite(solution) → bool`, `getGlobal() → [top_solutions]`.

### REPLAY-1: Реплей-воркер
- **Файл:** `replay_worker.js`
- **Задача:** ночной перезапуск топ-100 удачных траекторий.
- **Запуск:** pm2, cron в 02:00.

### BIOFIELD-1: Биоэлектрическое поле
- **Файл:** `memory/biofield.js`
- **Задача:** in-memory шина для сигналов между агентами.
- **API:** `emit(signal)`, `on(signal, cb)`.

### VOTE-1: Голосование колонок
- **Файл:** `race.js` (расширить)
- **Задача:** для сложных задач — взвешенное голосование.
- **API:** `vote(results) → winner`.

### PID-1: PID-регулятор критичности
- **Файл:** `sentinel.js` (расширить)
- **Задача:** держать load на грани хаоса (1.5–3.0).
- **API:** `regulate(load) → {throttle, boost}`.

## Порядок внедрения

1. **PHIL-1** (готов) → манифест
2. **CRITIC2-1, RIGID-1, SELFAWARE-1** → усиление агентов
3. **INTERO-1, PID-1** → гомеостаз системы
4. **PUPPET-1** → оркестратор
5. **GNW-1, BIOFIELD-1, VOTE-1** → коллективный интеллект
6. **REPLAY-1** → память
7. **POLY-1, CHRONO-1** → полифония и хронотоп

---

## Критерий успеха

- **Стабильность:** load 1.5–3.0 в течение 24ч
- **Эффективность:** бюджет < $0.50/ночь
- **Качество:** winrate > 50% на сложных задачах
- **Эволюция:** 5+ новых поколений агентов за ночь
