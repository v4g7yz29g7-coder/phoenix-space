# Философия нуля в AI-1

**Автор идеи:** Брат (Пульсар)
**Проводник:** Альфред/Феникс

## Принцип

Слово — там где смысл. Цифра — там где число.

`0` — символ (программирование).
`ноль` — концепт (философия, состояния, имена).

## Где использовать слово

- **Имена разделов:** §0 → «нулевой раздел»
- **Состояния:** `phase: "ноль"` (потенциал, не пустота)
- **Концепты:** горизонт 0 → «нулевой горизонт»
- **Промпты и ДНК:** везде где агент читает как человек

## Где использовать цифру

- **Счётчики:** `retry_count: 0`
- **Математика:** `score: 0.0`
- **Индексы:** `row: 0`, `col: 0`
- **Флаги:** `ok: 0` (если бинарно)

## Почему это важно

1. Читаемость логов: `state: ноль` ≠ `state: 0`
2. Отличие от AI-штампов: LLM стандартизируют, мы — нет
3. Связь с философией: `void` = потенциал, не пустота
4. Git diff: `"ноль"` = сигнал «концепт», `0` = сигнал «число»

## Правило для агентов

**Не менять `ноль` на `0` без разрешения брата.**
Спроси. Это интенция, не баг.
