## 1. Фонетика и просодия

### 1.1. Что такое фонетика

**Фонетика** — раздел лингвистики, изучающий звуковую материю речи:
артикуляцию, акустику и восприятие. В контексте цифрового двойника фонетика
отвечает за «что именно произносится» — набор фонем, аллофонов и их
коартикуляцию.

Ключевые понятия:
- **Фонема** — минимальная смыслоразличительная единица (в русском ~42 фонемы,
  в английском ~44).
- **Аллофон** — конкретная реализация фонемы в контексте.
- **Фонетическая транскрипция** — МФА (IPA), X-SAMPA, ARPABET.
- **Графемно-фонемное преобразование (G2P)** — текст → последовательность
  фонем; критично для TTS (grapheme-to-phoneme).

### 1.2. Что такое просодия

**Просодия** — надсегментный уровень: то, *как* произносится фраза. Это
«мелодия» речи и главный носитель идентичности голоса.

Компоненты просодии:
- **F0 (основная частота / pitch)** — высота тона, измеряется в Гц, логарифм
  даёт полутоны; диапазон F0 — ключевая характеристика пола и личности.
- **Интонация** — движение F0 по фразе (восходящий/нисходящий контур).
- **Длительность / темп** — скорость речи, паузы, длина гласных.
- **Энергия / интенсивность** — громкость, ударение.
- **Ритм** — чередование ударных и безударных, изохрония.
- **Тембр** — спектральная оболочка (форманты F1–F4), качество голоса.

### 1.3. Зачем это цифровому двойнику

- **Идентичность**: тембр + F0-статистика + темп делают голос узнаваемым.
- **Естественность**: правильная просодия убирает «робота» в синтезе.
- **Эмоция**: валентность и arousal кодируются в F0-контуре и энергии.
- **Персонализация**: для клонирования нужно ≥3–30 сек чистого аудио.
- **Письмо→голос**: даже анализ текста (пунктуация, длина фраз) даёт
  просодические подсказки (см. `voice_analyzer.js`).

  промптом; решает задачи паузы, интонации «профессионального диктора».
- **Tortoise-TTS** — высокое качество, медленный, открытый.
- **Bark (Suno)** — генеративный аудио, нелингвистические звуки.
- **OpenVoice (MyShell, MIT 2023/24)** — tone color conversion + клонирование.
- **StyleTTS 2 (Columbia, 2023)** — стиль через diffusion, human-level MOS.

## 3. Что нужно для аудио-анализа

### 3.1. Форматы и частоты

- **WAV (PCM 16-bit, 16/22.05/24/44.1/48 kHz)** — стандарт для обучения.
- **FLAC** — lossless сжатие, для архивов.
- **MP3/OGG/AAC** — lossy, только для инференса/доставки.
- **Моно, 22.05 kHz** — типичный компромисс для TTS.
- Каноническая частота анализа просодии: **16 kHz** (Whisper), **22.05 kHz**
  (VITS/Coqui).

### 3.2. Библиотеки Python

- **librosa** — загрузка, STFT, mel-спектрограммы, pitch (pyin/yin).
- **torchaudio** — I/O + transforms, работает на GPU.
- **soundfile / librosa.load** — чтение WAV/FLAC.
- **pydub / ffmpeg** — конвертация, нарезка, нормализация громкости.
- **pysptk / world (pyworld)** — WORLD-вокодер: F0, спектр, апериодичность.
- **Praat / parselmouth** — эталон просодического анализа (F0, jitter, shimmer,
  formants), скриптуемый Python-биндингом.
- **opensmile** — набор акустических признаков (eGeMAPS, ComParE).
- **numpy/scipy** — базовые DSP.

### 3.3. Метрики аудио-анализа

- **F0**: mean, median, std, диапазон, контур (ToBI-разметка).
- **Jitter / Shimmer** — микро-нестабильность голоса.
- **HNR** — гармоничность к шуму.
- **Форманты F1–F4** — вокалический тембр.
- **Tempo (syllables/sec), pause ratio** — ритм.
- **MOS** (1–5) — субъективное качество; объективно — MCD, WER, SECS (speaker
  embedding cosine similarity).

### 3.4. Аудио-датасеты (для клонирования)

- **LibriSpeech, VCTK, LJSpeech, Common Voice, Multilingual LibriSpeech.**
- **Русские**: RuLS, OpenSTT, Golos, Russian LibriSpeech.
- Требования: чистота (SNR > 20 dB), одна говорящая, без музыки/эха.

## 4. Как встроить в Архитектора

### 4.1. Pipeline «text → audio»

```
text (corpus/architect/dialogues/*.json)
        │
        ▼
 [1] Text Normalization  → числа, аббревиатуры, даты
        │
        ▼
 [2] G2P / Phonemization  → IPA / X-SAMPA
        │
        ▼
 [3] Prosody Prediction   → F0-контур, паузы, ударения
        │   (анализ пунктуации и длины фраз — voice_analyzer.js)
        ▼
 [4] Acoustic Model       → mel-спектрограмма (VITS/Tacotron/VALL-E)
        │
        ▼
 [5] Vocoder              → waveform (HiFi-GAN, BigVGAN)
        │
        ▼
 [6] Speaker Embedding    → клонирование тембра (speaker encoder)
        │
        ▼
   audio (WAV)
```

### 4.2. Двойной контур: анализ ↔ синтез

- **Анализ**: из голосовых сэмплов брата извлечь speaker embedding (ECAPA-TDNN,
  d-vector, x-vector) → «ДНК голоса».
- **Текстовая просодия**: `voice_analyzer.js` уже оценивает ритм письма
  (средняя длина сообщения и т.д.) — это прокси просодии двойника.
- **Синтез**: TTS с условным промптом (текст + embedding + F0).

### 4.3. Интеграция в архитектуру Архитектора

- **Модуль** `architect/voice_analyzer.js` — текстовая просодия.
- **Модуль** `architect/speech_synth.py` — обёртка над TTS-бэкендами.
- **Слой** `architect_dna.md` — добавляет просодический профиль в ДНК.
- **Хранилище**: `corpus/architect/audio/*.wav` + `.json` с метриками.
- **Конфиг**: выбор бэкенда (whisper / elevenlabs / coqui) через env.

### 4.4. Рекомендации по инференсу

- Для **быстрого прототипа**: ElevenLabs API (instant clone).
- Для **offline/self-hosted**: XTTS-v2 (Coqui) на GPU ≥6 GB.
- Для **транскрипции/анализа**: Whisper large-v3 (faster-whisper).
- Для **русского**: Yandex SpeechKit (синтез) + Whisper (ASR).

## 5. Инструменты

### 5.1. Yandex SpeechKit

- Облачный API: **STT** (потоковая и пакетная), **TTS** (нейронные голоса,
  SSML-разметка: `<prosody>`, `<emphasis>`, паузы).
- Сильные стороны: русский язык, омниканальная запись, диаризация.
- Интеграция: REST/gRPC, Python SDK.
- Кейс: озвучка реплик двойника с индивидуальным голосом (brand voice).

### 5.2. OpenAI Whisper

- Мультиязычный ASR (99 языков), модели tiny→large-v3.
- Даёт таймстемпы слов → основа для просодического анализа и диаризации.
- `faster-whisper` (CTranslate2) — 4× быстрее на CPU.
- Роль: транскрипция пар user+assistant из аудио в текст для ДНК.

### 5.3. ElevenLabs

- Instant Voice Cloning (от ~1 мин аудио), Professional Voice Cloning
  (высокая точность).
- Многоязычный v2, управление стабильностью/сходством (stability/similarity).
- Роль: быстрое качественное клонирование голоса-двойника.
- Ограничение: облако, стоимость, приватность.

### 5.4. Coqui TTS

- Открытый фреймворк (ex-Mozilla TTS).
- Модели: **XTTS-v2** (zero-shot clone, 17 языков), VITS, Tacotron2+HiFi-GAN.
- Полностью локальный, GPU/CPU, torch.
- Роль: self-hosted клонирование без облака и лимитов.

### 5.6. Итоговые рекомендации для Архитектора

1. **ASR**: Whisper (`faster-whisper`) для оффлайн-транскрипции диалогов.
2. **TTS/VC**: XTTS-v2 локально для приватности, ElevenLabs — для качества.
3. **Русский продакшн**: Yandex SpeechKit с SSML-просодией.
4. **Просодический анализ**: parselmouth/opensmile + `voice_analyzer.js`.
5. **Хранение ДНК голоса**: speaker embedding + F0-статистика в JSON.
