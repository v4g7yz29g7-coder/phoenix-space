# Champion Tiebreak: Стратегии гибридных агентов

1. **Маршрутизация по сложности (Complexity Routing).** Гибридный агент оценивает задачу и направляет её либо быстрому «реактивному» модулю (шаблонные операции, короткие запросы), либо «делиберативному» модулю с планированием и цепочкой рассуждений. Это даёт скорость на простых задачах и глубину на сложных без переплаты по токенам/времени.

2. **Слияние правил и моделей (Rule + Model Fusion).** Детерминированные правила и эвристики обрабатывают критичные и предсказуемые шаги (валидация, безопасность, форматирование), а LLM отвечает за неоднозначные, творческие и языковые части. Решение принимается как гибрид: правила задают жёсткие рамки, модель заполняет вариативность.

3. **Ансамблевый тайбрейк (Champion–Challenger Tiebreak).** Если два гибридных агента (или два модуля) дают конкурирующие результаты, спор разруливает арбитр: голосование, оценка уверенности или отдельная модель-судья выбирает победителя по метрике ценности (точность, стоимость, задержка). Один агент назначается «чемпионом» по умолчанию, второй оспаривает его только при значимом приросте качества.
