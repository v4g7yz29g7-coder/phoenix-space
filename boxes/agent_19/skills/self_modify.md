# 🛠️ SKILL: self_modify

## Цель
Научить агента читать свой код, находить улучшения, применять патчи и коммитить.

## Инструменты
- `read_file(path)` — читать файл
- `write_file(path, content)` — перезаписать файл
- `edit_file(path, old, new)` — заменить фрагмент
- `apply_patch(patch)` — применить git-патч
- `run_command(cmd)` — выполнить bash
- `git_commit(message)` — закоммитить

## Алгоритм
1. Получить задачу от пользователя (или свою инициативу).
2. Прочитать `ARCHITECTURE.md` и `KNOWLEDGE.md` для контекста.
3. Найти нужный файл через `grep` или `find`.
4. Прочитать его через `read_file`.
5. Сгенерировать изменение (патч или новый контент).
6. Применить через `edit_file` / `apply_patch`.
7. Проверить синтаксис: `node --check <file>`.
8. Если ок — `git_commit("auto: <описание>")`.
9. Если ошибка — откатить (`git checkout <file>`) и попробовать иначе.
10. Записать в `memory/YYYY-MM-DD.md`.

## Правила
- Менять только файлы в `/home/ishidin/phoenix`.
- Не трогать `.env`, `node_modules`, `*.db`.
- Всегда коммитить после успешного изменения.
- При сомнениях — спросить брата.
